# Kavery Website

> Next.js + TypeScript | Client Project

## About
Client website for Kavery. Built with Next.js and TypeScript.

## Key Facts
- **Framework**: Next.js (App Router or Pages Router)
- **Language**: TypeScript
- **Dev**: `npm run dev`
- **Build**: `npm run build`
- **Lint**: Check `eslint.config.mjs`

## Rules
1. Follow Next.js conventions — use `app/` or `pages/` directory structure
2. Use `next/image` for optimized images
3. Use `next/font` for fonts
4. Server components by default, `"use client"` only when needed
